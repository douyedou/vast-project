## 二、环境准备（测试前必做）

### 步骤 1：拉取最新代码

```bash
git checkout main
git pull origin main
```

### 步骤 2：安装新增依赖

```bash
# 在 nextjs 容器内执行
docker-compose exec nextjs pnpm install

# 或在宿主机执行
cd vast-project
pnpm install
```

### 步骤 3：重置数据库（Schema 已变更，必须重置）

```bash
# 停止并删除数据卷
docker-compose down -v

# 重新启动（会自动执行新的 schema.sql + seed-data.sql）
docker-compose up -d

# 等待 Ollama 模型拉完
docker-compose logs -f ollama
```

### 步骤 4：执行 M06 知识库迁移

```bash
# 在 nextjs 容器内执行
docker-compose exec nextjs pnpm db:migrate:m06-knowledge
```

### 步骤 5：重新向量化知识库

```bash
# 在 nextjs 容器内执行
docker-compose exec nextjs npx tsx scripts/embed-knowledge-base.ts
```

> ⚠️ 因为新增了 `knowledge_chunks` 表，旧的知识库数据需要重新处理。

